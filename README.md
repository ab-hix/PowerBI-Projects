🏥 Hospital Patients Analytics Dashboard
📌 Project Overview

This project is a Power BI dashboard created to analyze hospital patient data, offering deep insights into patient demographics, disease trends, and treatment outcomes. The dashboard empowers healthcare administrators and doctors to make data-driven decisions for better patient care and hospital management.

💼 Business Use Case

Monitor patient admissions and discharges for efficient resource allocation.

Track disease-wise and age-group distribution to understand healthcare demand.

Analyze patient status (inpatient/outpatient) for improved planning.

Support hospital management with real-time insights for operational efficiency.

Enhance strategic decision-making by identifying key patient trends.

⭐ Features

📊 Interactive visuals on patient data by age, gender, and disease type.

📅 Date-wise admission and discharge analysis.

⚖️ Toggle between average vs. median values for flexible insights.

🩺 Patient classification (status, severity, recovery trends).

🔍 Filters and slicers for dynamic exploration (date, disease, demographics).

🛠 Tools & Technologies

Power BI – Dashboard creation & visualization

Excel / CSV Dataset – Data source

Power Query – Data cleaning & preprocessing

DAX – Calculated measures & KPIs
